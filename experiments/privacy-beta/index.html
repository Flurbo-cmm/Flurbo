Keep the note secret.

This browser demo makes a real zero-knowledge membership proof using four simulated notes. It does not deposit money, trade or send a transaction. The separate vault rehearsal tests funded withdrawals on a disposable EVM.

1. Create a demo note

A note is a secret you must keep to prove ownership. Your Flurbo login cannot recover it.

2. Back up and recover

The password and note secret stay in this browser. Keep the backup and password separately. This demo does not save either to your account.

3. Prove without identifying the note

The proof reveals the group, message, scope and nullifier. It does not include the secret note or its deposit index. The nullifier lets a verifier reject repeated spends in the same vault scope.

What this does not hide

Asset type, fixed amount, deposits, withdrawals, recipients and timing remain public. Small groups and reused funding or withdrawal addresses can reveal links. All four notes here come from one browser, so this is not evidence of anonymity among real users.

This is a prototype of private ownership, not private trading. No existing Flurbo bet becomes private. There is no audit or real-value deployment claim.
