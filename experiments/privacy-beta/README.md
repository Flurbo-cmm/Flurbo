# Flurbo privacy ownership experiment

Real Semaphore proofs, encrypted note recovery and a fixed-lot vault on a disposable local EVM. **Not private trading or a deployed Monad vault.** The browser lab uses simulated notes without assets.

This remains an operator-only local experiment bundled by the current Docker build. It is outside the market and settlement contracts.

Keep `node_modules`, `public`, `dist`, note backups and generated reports out of Git. Never use a real wallet key with the local rehearsal.
